# Deep Sea Serpent

A glowing snake game set in the deep ocean. Eat plankton to grow; every 5 you eat takes you one level deeper, from the Sunlight Zone down to Challenger Deep, with new colours and slightly faster water. Swim off any edge to come out the other side.

Play: https://johnson-codes.github.io/deep-sea-serpent/

- Arrow keys or WASD to steer, Space or P to pause
- On phones: swipe on the board or use the on-screen pad
- Golden pearls are worth 5× points

Plain HTML, CSS and JavaScript in a single `index.html`. No build step.
